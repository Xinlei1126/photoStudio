# Lumen & Frame — Photography Studio Website

A complete fictional photography studio website created for **Project 2 – Modern Business Website**.

Visit link: https://xinlei1126.github.io/photoStudio/

## Business idea

- **Business name:** Lumen & Frame
- **Type of business:** Boutique photography studio
- **Location:** Stockholm, Sweden (fictional address used in the site)
- **Target customers:** Couples, families, founders, small brands, event organisers and creative professionals
- **Main services:** Portraits, weddings, brand/product photography and event photography

> All names, prices, reviews, contact details, addresses and images in this project are fictional/demo content for coursework.

## Sitemap / page structure

This is a responsive single-page website with the following sections:

1. Home / Hero
2. About
3. Services
4. Gallery / Featured work
5. Client testimonial
6. Contact form
7. Footer

## Design plan

- **Style:** Modern, editorial, warm and minimal
- **Colors:** Off-white, charcoal, sage and rust
- **Typography:** Playfair Display for headings and DM Sans for body text
- **Layout:** CSS Grid and Flexbox
- **Responsive breakpoints:** Desktop, tablet and mobile

## JavaScript interactions

- Responsive mobile navigation menu
- Filterable gallery
- Gallery lightbox/modal
- Contact-form validation and demo success message
